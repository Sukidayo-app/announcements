## 🐾 チュートリアル・初期設定について {#tutorial}

### どうやったら始められますか？

以下の手順でご利用いただけます。

**招待を行う側**
1. サインインを行い、「新しくはじめる」を押す
2. プロフィールを入力し、自分の動物を選ぶ
3. 一問目の質問に回答
4. パートナーを招待
5. チュートリアル終了後、決まった時間にふたりに質問が届くようになります 💌

**招待された側**
1. 「招待コードではじめる」をタップし、招待コードを入力
2. プロフィールを入力し、自分の動物を選ぶ
3. 一問目の質問に回答
4. チュートリアル終了後、決まった時間にふたりに質問が届くようになります 💌

### 名前や性別、動物の名前はあとから変更できますか？

名前・性別・動物の名前、すべて変更可能です。マイページ右上のメニュー → 設定 → 基本設定 から変更できます。ただし動物そのもの（種類や色）は変更できません。

### 通知が来ません。どうしたら通知が届くようになりますか？

通知が許可されていない可能性があります。端末の設定からアプリ通知をONにしてください。

### 質問が届きません。どうしたら届くようになりますか？

相手がまだ回答していない可能性があります。ふたりの回答がそろった状態で配信時間になると、次の質問が配信されます。ご自身が回答しているかどうか、パートナーが回答しているかどうかをご確認ください。

## 📝 一問一答・カップル診断・回答について {#qa}

### 回答結果はどうしたら確認できますか？

ふたりの回答がそろったタイミングで、お互いの内容が表示されます。先に回答した場合は、相手が答えるまで内容は非表示です。

### 間違って回答してしまいました。やり直しや修正はできますか？

現在は、日々の質問の回答のみ修正が可能です。カップル診断の回答は編集いただけません。回答へのコメント機能や、口頭でのコミュニケーションで補足してみてください。

### 回答へコメントをしたら、相手に通知が届きますか？

はい、コメントを送信すると相手にプッシュ通知が届きます。また、アプリ内でも赤いバッジで通知が表示されます。

### パートナーには質問が届いているのに、自分には届かない場合は？

ペアの回答がそろっているにも関わらず、片方にのみ次の質問が届くケースを確認しております。不具合の可能性がありますので、メニューの「お問い合わせ」よりご連絡ください。

### 過去に回答した質問や回答結果が表示されなくなってしまいました。

通信の混雑具合などで一時的に表示されないケースがあります。時間をあけて再起動してみてください。1日待っても表示されない場合はお問い合わせください。

## 📷 ふたりの思い出機能について {#memories}

### 思い出の登録はいつからできるようになりますか？

毎月1日からその月の思い出をアップロードできるようになります。ふたりの記録 → 思い出タブ の＋ボタンから登録してください。また、毎月25日12:00〜翌月3日23:59の期間にはホーム画面にもバナーが表示されます。

### 一度登録した思い出の編集はできますか？

写真および「思い出にひとこと」の編集は可能です。ふたりの記録 → 思い出タブ → 編集したい思い出 → 右上の編集アイコンをタップしてください。コメントの編集はできません。

## 🛠 設定・機能について {#settings}

### 質問が届く時間は変更できますか？

誘った側の人（招待コードを送った人）のみ変更可能です。1時間刻みで設定でき、設定はふたりで共有されます。マイページ右上のメニュー → 設定 → 基本設定 → 質問の配信時間 から変更できます。

### ログアウトしたいときはどうしたらいいですか？

マイページ右上のメニュー → その他 → ログアウト から操作可能です。確認画面の表示後、アプリ起動時の画面に戻ります。

### 機種変更などでデータを引き継ぐにはどうしたらいいですか？

以前と同じアカウントでログインすることでデータが引き継がれます。

※異なるアカウントを使用した場合は、別アカウントとして新規利用となりますのでご注意ください。

- 「Googleでサインイン」をご利用の場合は、引き継ぎ元・先で同一のGoogleアカウントでサインイン
- 「Appleでサインイン」をご利用の場合は、引き継ぎ元・先で同一のApple IDでサインイン

【参考】[サブスクリプション契約中に機種変更した場合、契約は引き継がれますか？](#subscription)

### サインインしたら新しく開始する画面になりました。どうしたらいいですか？

ログアウト前・機種変更前に使用していたアカウントと異なるアカウントでサインインを実施してしまうと、別アカウントの新規利用としてチュートリアルが開始されます。

以前使用していたアカウントと同一アカウントでサインインされた場合、サインイン後すぐにRiamoのホーム画面が表示されます。ホーム画面が表示されない場合は、異なるアカウントでサインインされている可能性がございますので、別のアカウントでのサインインをお試しください。

誤って新規アカウントで開始してしまった場合、チュートリアル右上の三点リーダー(…)よりログアウトもしくはアカウントの削除を実施いただき、アカウントを確認の上、再度サインインをお試しください。

### 同居状況は変更できますか？

はい、下記の手順で設定の変更が可能です。

マイページ右上の歯車アイコン → メニュー画面 → 基本設定 → ペアの情報 → 同居状況

変更後に迎えた配信時間から、新しい同居状況に対応した質問が届きます。

### 記念日に未来の日付は設定できますか？

申し訳ございませんが、現在は未来の日付は設定いただくことができません。

## 📅 記念日について {#anniversary}

### 削除や名前の変更ができない記念日があります。なぜですか？

交際記念日・自分の誕生日・パートナーの誕生日・Riamoを始めた日の4件はデフォルトの記念日として自動で作成されるため、削除や名称の変更をすることができません。

### 記念日の並び順を変えたいのですが

記念日の並び順は、次回の日付が近い順に自動で並ぶ仕様となっており、手動で並び替えることはできません。

## 💌 メッセージカードについて {#message-card}

### 送信済みのメッセージカードを削除・編集できますか？

送信済みのメッセージカードは編集・削除ができません。送信予約中のカードは、送信前であれば編集・削除が可能です。

### パートナーと離れて暮らしています。メッセージカードのお届け時間はどの時間帯で設定されますか？

メッセージカードの送信予約時間は、受け取る相手のタイムゾーンが適用されます。例えば8:00に届くよう設定した場合、相手の現地時間の8:00に届きます。

## 🚪 退会やペア解除について {#account}

### 退会やアカウント削除をするにはどうしたらいいですか？

Riamoでは「退会」ではなく、アカウント削除という形で手続きが可能です。下記の手順で、アプリ内からアカウント削除を行っていただけます。

マイページ右上のメニュー → 設定 → アカウント管理 → アカウントの削除

アカウントを削除されますと、回答データ等が削除され、現在のデータの復元は行えませんのでご注意ください。また、サブスクリプションにご契約の場合は、自動的に解約とはなりません。別途解約のお手続きをお願いいたします。

【関連】[サブスクリプションを解約するにはどうしたらいいですか？](#subscription)

### ペアを解除するにはどうしたらいいですか？

Riamoはペアでの実施を前提としており、【ペア解除】ではなく、退会（アカウント削除）でのご案内をしております。

【関連】
- [ペアがアカウントを削除したらどうなりますか？](#account)
- [退会やアカウント削除をするにはどうしたらいいですか？](#account)

### ペアがアカウントを削除したらどうなりますか？

Riamoはペアの実施を前提としており、ペア解除後（パートナーのアカウント削除後）はペアの方単体でご利用いただくことができません。

パートナーがアカウントを削除したタイミングで、ペアの方の画面にはパートナーがアカウントを削除した旨と、アカウント削除の承認を求める通知が表示されます。

例えばAさんとBさんのカップルの場合は下記のような状態となります。
- Aさんがアカウント削除を行う
- BさんのRiamo画面にパートナーのアカウント削除の通知と、今後の利用ができなくなるため、Bさんのアカウント削除の同意を求める通知が表示される

## 💳 サブスクリプションについて {#subscription}

### サブスクリプションの契約でどんな機能が使えますか？

以下の機能をご利用いただけます。

- 広告なしでアプリをご利用いただけます
- カップル診断のサブスクリプション限定テーマが利用できます
- やりたいことリストのカスタマイズ（カテゴリの追加・編集・削除）が可能です
- 毎月の「ふたりの思い出」で登録できる写真の枚数UP
- 達成したやりたいことに登録できる思い出の枚数UP

現在Riamoはβ版として公開しており、皆さまからのご意見などをもとに、正式版に向けて提供機能や料金設定を調整している段階です。ご希望の機能などがございましたら、アプリ内のご意見ボックスよりお気軽にご意見をお寄せくださいませ。

### 有料機能の利用にはふたりとも加入が必要ですか？

いいえ、どちらか1名が加入することでふたりで有料機能を利用できます。

### サブスクリプションを解約するにはどうしたらいいですか？

アプリ内ではなく、Google PlayもしくはApp Storeでの手続きが必要です。詳しくは以下のページをご確認ください。

- [Google Playでの定期購入の解約・一時停止・変更（Google Playヘルプセンター）](https://support.google.com/googleplay/answer/7018481)
- [Appleでのサブスクリプション解約手順（Appleサポート）](https://support.apple.com/ja-jp/118428)

### 解約したらすぐに有料機能が使えなくなりますか？

いいえ、期間途中で解約した場合でも、次回更新日までは引き続きご利用いただけます。例：7月31日までの契約の場合、7月29日に解約しても31日まで利用可能です。

### 利用していた有料機能（有料質問の回答結果や追加したやりたいことのカテゴリ等）は解約後に閲覧できなくなりますか？

回答済みの有料版のカップル診断結果は解約後も引き続きご確認いただけます。ただし、サブスクリプション契約中に作成した、やりたいことリストのカテゴリは解約後閲覧することができません。解約後、追加されたカテゴリに含まれるやりたいことリストは非表示となります。

### サブスクリプション契約中に機種変更した場合、契約は引き継がれますか？

サブスクリプションの契約情報は、Riamoのログインアカウントではなく、購入時に使用したApp Store / Google Playのアカウントに紐づいています。機種変更後は、購入時と同じアカウントでApp Store / Google Playにログインしたうえで、サブスクリプション購入画面の【購入の復元】をお試しください。

※ 異なるOS（Android → iOS / iOS → Android）間では、サブスクリプションの引き継ぎはできません。その場合は、購入時のストアでサブスクリプションを解約したうえで、新しいOSのストアからあらためてご購入ください。

- [Google Playでの解約](https://support.google.com/googleplay/answer/7018481)
- [Appleでの解約](https://support.apple.com/ja-jp/118428)

### 契約しているのに有料機能が使えません。

サブスクリプションの契約情報は、Riamoのログインアカウントではなく、購入時に使用したApp Store / Google Playのアカウントに紐づいています。ストアのアカウントがサブスクリプションを契約しているアカウントであるかをご確認ください。サブスクリプションを契約しているアカウントであるにもかかわらず、有料機能がご利用できない状態の場合は、お手数ですがアプリのマイページ右上のメニュー「お問い合わせ」からサポートへご連絡いただきますよう、お願いいたします。

## 🎁 お楽しみ要素について {#fun}

### 家具などのアイテムはどうやったら増えますか？

日々届く質問にふたりで回答をしていくと、新しい家具が追加されます。何問目で家具がGETできるかは、ホーム画面に表示される"次の家具まで○問"でご確認ください。

### 家具へのカウントダウンが消えてしまいました。なぜですか？

現在、一定数まで質問にご回答いただくと家具の取得が終了する仕様となっており、最後の家具まで取得するとカウントダウンが消えるようになっております。

なお、今後はリニューアルを予定しており、家具・アイテムの配置や取得方法などを含めて変更を予定しております。

## ❓ その他 {#other}

### 質問がちょっと難しい・気分が乗らない時はどうしたらいいですか？

無理に答える必要はありません。「また明日やろうね」という気軽な気持ちでOK！質問は毎日配信されるので、ご自身のペースで続けてくださいね。

### 不快な広告が表示されました。対応してもらえませんか？

ご不快な思いをおかけして申し訳ありません。不適切なカテゴリの広告が表示されないようブロック設定を行っておりますが、一方で、広告元のアプリ自体がセキュリティソフトやAIツール等として配信されている場合、広告内の表現が悪質・不安をあおる内容であっても、事前に完全に判別しきれないケースがございます。お手数ですが悪質な広告が表示された場合は、スクリーンショットを取得の上、お問い合わせフォームよりご連絡ください。

なお、広告表示や課金機能につきましては、本アプリを安定して運営し、より良い機能開発を継続していくために設定させていただいております。何卒ご理解いただけますと幸いです。
